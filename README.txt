Author: Nerijus Čepulis (VU MIF IT Bachelor's Project, year 4)

The project is a Crypter implementation, developed for a Bachelor's project.

The program is written in C++.

The functionality of the program involves obfuscating given malicious payloads, utilizing 
payload fragmentation, shuffling, and encryption logic. Additionally, the created Stub file is equipped with 
Process Hollowing Injection logic, meant for masking the payload with a legitimate system process.
Additionally, the implementation allows for persistence and fileless payload storage, allowing the program to stay
on the target's system and establish Command and Control.

The project is meant for educational purposes, to demonstrate techniques attackers could utilize in exposing systems,
in hopes that the research will help detection software increase their defenses.
